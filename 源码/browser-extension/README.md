# 梦藏 · 网页收录

Chrome / Edge 的本机扩展 0.3.0。网页、图文文章、选中文字和图片直接保存到梦藏当前资料库，不调用 AI，不读取浏览历史，不上传到云端。

## 安装

1. 保持支持浏览器收录的梦藏桌面版打开。
2. 双击本文件夹中的「安装本机连接.command」。本机连接需要 Node.js 22 或更新版本，只注册本扩展的 Chrome / Edge Native Messaging 入口。
3. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。启用开发者模式，选择「加载已解压的扩展程序」，选中本文件夹。
4. 在浏览器工具栏固定「梦藏 · 网页收录」。面板显示「已连接梦藏资料库」后即可保存。

从 0.1.0 更新时，先更新梦藏并重新运行本机连接安装脚本，再在扩展管理页重新加载此扩展。扩展 ID 和本机资料库不变，旧待保存请求仍可使用原编号重试。

为了沿用 Chrome 已加载的路径，原「梦藏浏览器扩展-0.1.0」文件夹也可原地升级到本版；实际版本以 `manifest.json` 的 0.3.0 为准。旧 0.1.0、0.2.0、0.2.1 和 0.2.2 ZIP 保留作程序回退包，不包含个人资料。

0.2.1 修复没有 `article` 或 `main` 元素的旧网页中标题层级被压平成段落的问题。修复用于之后新收录的文章，不自动改写已有资料。

扩展固定 ID 为 `ebdbkhhcgifolblbcpkpgibjbighfhgi`。请保留 `manifest.json` 中的公钥；它不含私钥，作用是保持本机连接所允许的扩展 ID 稳定。

0.2.2 修复已删除收藏集的旧选择无法解除、失败待办积满后无法恢复保存，以及文章导语、隐藏副本、表格和编号列表的收录问题。阅读器重选会保留未提交备注与标星，长文提供快捷保存入口。失效选择与待办只在明确操作后移除；不会删除梦藏中的资料。旧文章保持原样，新结构用于之后的收录。

## 使用

- **保存网页截图**：点击「保存网页截图」把当前标签可见的画面存为图片卡；要保留局部，点「框选截图」，在预览上拖出范围，点「保存选区」。截图保留当时的页面标题和网址。原尺寸 PNG 能放入本机传输时保留 PNG；较大的画面会压缩。关闭或取消框选不会保存。截图不含浏览器工具栏，也不自动滚动截整页。
- **剪藏后的相关资料**：保存成功后，面板直接显示最多三条自己库中已保存的资料，列出同一网页、共同标签、收藏集或标题的关联依据。点一条，可在梦藏打开它。没有匹配或查询暂时失败都不影响已保存的卡片；右键收录后再打开面板也可以查看。

- **保存网页**：点击扩展，选择「保存网页」，保存网址、标题和简介。
- **保存图文文章**：保存当前页面已加载的文字、标题层级、段落、普通链接、粗斜体与图片位置。梦藏下载可取得的公开图片原文件；无法下载或没有普通公开地址的图片显示明确占位，不会假装已存图片。不会读取表单、密码字段、脚本或导航文字；不复制网站原 CSS、脚本或互动组件。页面开启翻译时，保存当前显示的文字。
- **保存选中文字为高亮**：选中文字后使用工具栏按钮，或右键选择「保存选中文字到梦藏」。同时保存前后文与原文位置；选区变化时要求重新选择，不保存一个猜测的位置。
- **收藏集、备注和标星**：面板内可多选收藏集、填写备注和标星，和正文在一次保存中提交。收藏集与标星设置也用于之后的右键收录；备注只用于当前页面，并在成功保存后清空。取消所有收藏集会只存入资料库。
- **重新显示和定位**：打开扩展会读取本页已经保存在梦藏中的高亮并显示。点击某条高亮的「定位」可滚动到对应句子；原文改变或重复句无法可靠分辨时会明确提示，不跳到另一个相似句子。
- **按网站自动高亮**：默认不开启全站读取。点击「开启此网站自动高亮」并同意 Chrome 的当前域名权限后，这个域名上的网页可在重新打开时显示已保存高亮。其他域名不会获得权限；关闭时撤销对应权限并注销该域名的自动脚本。自动功能只读取与当前网页 URL 对应的高亮，不接受网页传入的其他 URL。
- **保存图片**：在图片上右键，选择「保存图片到梦藏」。梦藏从该公开图片地址下载原图片，保存图片文件和来源页面。需要登录或没有普通图片地址的内容，可先下载后从软件导入。
- **保存失败**：打开梦藏后，在扩展面板点击对应条目的「重试」。原请求身份保留，重试不会重新抽取网页，也不会因回执丢失重复新增卡片。永久失效或不再需要的待办可点击「放弃」并在行内确认，只移除此本机待办，不删除梦藏资料；未收到回执的内容可能已保存，重新收录可能新增卡片。正在执行的保存不能放弃。
- **已删除的收藏集**：扩展会核查已选收藏集，跨页的合法选择保留；已删除或未能核实的选择明确显示，可点击「解除选择」后重新保存。

浏览器内部页面、扩展商店页面不能收录。文章和单条高亮最多 50000 字；单篇文章最多 40 张图片，图片下载还受梦藏显示的单篇大小预算约束。超出时可选取需要的部分再收录。一次收录只读取你当前主动保存的页面；自动高亮只在你单独允许的网站运行。网页自动翻译、付费墙、动态内容或页面改版可能影响原文定位；无法可靠匹配时不会猜测。

本机连接默认位于用户自己的 `Library/Application Support/梦藏/Browser Extension Host`；连接凭据由梦藏管理，扩展不接触它们。已安装的连接不依赖源码目录。

## 命令行与验证

```sh
node scripts/install-native-host.mjs --dry-run
node scripts/install-native-host.mjs
```

在源码仓库中更新后，先运行 `node browser-extension/scripts/build-host.mjs`，构建独立 host 和网页高亮脚本，再重新安装连接并重新加载扩展。只读预览安装计划可用 `--dry-run`，隔离测试可指定 `--home <测试目录>`；日常安装不需要传入个人资料路径。

这不是商店发布版。安装扩展需要用户在浏览器的扩展管理页完成；卸载时可在同一页面移除扩展。连接注册文件只允许上面的固定扩展 ID，不放宽其他扩展的权限。
