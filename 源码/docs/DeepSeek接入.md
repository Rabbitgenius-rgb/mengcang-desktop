# 梦藏的 DeepSeek API 设置

核对日期：2026-10-04。此接入通过 DeepSeek 的兼容对话 API 处理文字，并在 0.8.2 增加明确确认后的图片输入。

## 在梦藏内配置

1. 打开「本机工具 → AI 连接与用量」。
2. 连接方式选择「兼容 OpenAI 的 API」，点「填入 DeepSeek 配置」。
3. 地址为 `https://api.deepseek.com/v1`，模型为 `deepseek-flash`。图片功能推荐使用此模型；`deepseek-v4-pro` 在本实现中仅用于文字。
4. 勾选「准备 API / CLI 生成连接」，将自己的 DeepSeek API 密钥填入应用内的密码输入框，再点「保存连接设置」。不要把密钥发到聊天中或写入项目文件。
5. 保存仅配置连接，不进行网络请求或生成。选定一张短文字素材并打开「核心概述」，核对原生确认框里的目的地址、模型及文字数量后，再决定是否「确认并调用」。取消不会发起请求。

尚未有密钥时，在 [DeepSeek 开放平台](https://platform.deepseek.com/api_keys) 创建。创建、充值与真实调用由用户决定。

## 适配范围

- 五种文字解读与 AI 分类共用这条连接。0.8.2 新增「图片内容描述」「构图与配色」；图片分类也使用同一连接。结果由用户明确另存或采用，不自动覆盖素材原文或图片。
- 对官方 `api.deepseek.com` 的解读和分类请求明确使用非思考模式，保留当前每次最多 1200 输出 token 和 60 秒超时；分类请求使用 JSON 模式，再校验标签及收藏集标识。截断或空结果报错，不自动重试。
- 官方 DeepSeek 当前没有梦藏所用的 Whisper 兼容音频转录接口。这条连接不提供播客自动转录；梦藏会在确认和上传音频前拒绝该请求。本机音频、字幕及片段功能仍可使用。
- 本机 OCR 与语义搜索由 Apple 本机引擎处理，不依赖 DeepSeek；其开关独立。
- 密钥通过 Electron 的系统加密保存在当前应用用户目录，绑定目的地址，不写入素材库、导出包或日志。

## 图片输入（0.8.2）

1. 导入一张本机原图，或选择资料库中能读取原文件的图片。支持 JPEG、PNG、GIF、WebP，单张不超过 8 MiB。只包含远程地址、封面缩略图而没有可读取原文件的素材不能直接送去解读。
2. 打开「图片内容描述」「构图与配色」或「分类建议」，先核对待发送原图、文件名和大小。预览只在本机准备，不会提前上传。
3. 点击「准备调用并确认」，在原生确认框里核对 API 地址、模型、图片文件名及大小，以及附带文字数量。只有点击「确认并调用」后才发送该张图片与所选素材文字；取消不会发送。
4. 生成结果可另存为文字笔记；分类建议需勾选采用。原文件保持不变。

图片功能需要支持图片输入的 API。当前 Claude CLI 适配仅处理文字；本机 OCR 是独立的文字识别功能，不能替代画面理解。对未支持图片的模型，梦藏会在上传前报错。

## 本轮验证

0.8.1 的文字连接已通过合成响应检查，并在 2026-10-04 经用户明确确认，完成 1 次真实中文文字解读，验证了文字请求连通。证据见 `verification/deepseek-20261004/06-real-deepseek-response.txt` 和该目录的 `acceptance.json`。0.8.2 的图片路径先通过非私密合成图片及本机模拟 API 验收，随后经用户逐次确认完成真实图片描述：正确识别白色背景、左侧红圆和右侧蓝色正方形，并完成解读另存、重开及测试卡片归档。证据见 `verification/vision-20261004/acceptance-status.json`。这只验证该简单合成图片的描述，不代表构图配色、分类或任意图片的输出质量已经验收。

## 本机结果草稿（0.8.3）

- 新发起的 AI 请求会保留本机状态、结果和所选素材快照。关闭工具、切换解读方式后，可以从「本机结果草稿」找回；读取草稿不会再次调用模型。
- 请求进行中关闭工具，仍会保存随后返回的结果。正常退出会等待当前请求；如果应用意外中断，重开后保留未完成状态，不自动重试。
- 磁盘写入失败时会明确提示结果仅留在当前窗口，请先复制或另存后再退出。
- 同一份解读始终对应同一张已保存笔记。再次保存不会新增副本、覆盖后来编辑的内容或恢复已归档笔记；保存后可直接打开已有笔记。
- 草稿保留原文件的名称、类型、大小和内容摘要，不复制原文件、图片编码、连接配置或密钥。
- 此机制从 0.8.3 开始生效。旧版本已关闭且未保存的结果无法恢复，之前产生的重复笔记不会自动删除。
