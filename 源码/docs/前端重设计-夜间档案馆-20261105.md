# 梦藏前端重设计 · 夜间档案馆（2026-11-05）

用户反馈：上一轮（左侧栏 + 统一色板）仍是在原有界面上修补。要求重新设计，以 Awwwards 等前端展示作参考，把梦藏当作一个“前端作品”来设计，而不是笔记软件的后台。

## 视觉系统

- 底色：墨夜 `#0c0d10`，层次靠细线（`#26272c`）与留白，不靠灰色色块。
- 纸张：资料“纸条”沿用此前用户确认过的“稳定四色、颜色不代表类别”的原则——宣 `#ebe5d8`、青 `#d3ddd5`、藕 `#e6d3cf`、缃 `#e9dcb6`，按卡片 ID 稳定分配。纸上文字为墨色 `#1c1a17`。
- 强调：月金 `#e3b866`，只用于当前项、未读与焦点。
- 字体：标题与引文用宋体（Songti SC / Noto Serif SC），界面与正文用苹方，编号/计数/日期用等宽数字（ui-monospace）。
- 浅色主题：纸色底 `#f1ece2`，墨字，细线 `#d9d2c4`；同一套变量。

## 页面结构

1. **顶部导航**：左“梦藏”字标；中部文字链接 回看 · 星空 · 资料库 · 收藏集 · 画布（当前项前加圆点）；右侧 添加 · 设置。没有侧栏。
2. **资料库**：刊头搜索句（`在梦藏里找…`，输入即搜）→ 细线控制栏（类型、结果数、排序/筛选、关键词/按意思、墙/目录/细看）→ 视图。
3. **墙**：CSS 多列，物件之间 12px 间隙，无卡片边框；图片原比例，文字为纸条，摘录为衬线引文纸，链接为“票据”（域名 + 标题）。悬停时下方出现编号与题名。
4. **目录**：细线分隔的行；悬停有图资料时预览跟随指针。
5. **细看**：一件资料居中放大，左侧题名，右侧类型与标签，下方露出下一件；← → 键切换。
6. **详情**：左侧物件/正文，右侧黏性规格表与操作；相关资料为横向条带。
7. **底部状态行**：本机保存状态、资料总数、当前视图。

## 约束

功能、数据、事务、AI 授权与已有交互全部保留；改变的是呈现层。编辑器、对话框沿用现有组件，仅换色。动效：视图切换与悬停为 160–240ms 透明度/位移，支持减少动态。只改源码与浏览器预览，不替换已安装应用。
