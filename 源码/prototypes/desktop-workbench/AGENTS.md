# 梦藏前端现行约束

- 唯一开发源码为本仓库的源码目录。0.8.6 和导入的 0.9.0 由 Git 标签保留，其他来源见根 README。
- 正式入口静态挂载 StandaloneApp，浏览器 preview.html 与桌面版共用 SublimeWorkspace，预览数据与正式资料库隔离。
- 2026-11-05 前端重设计「夜间档案馆」（用户要求推翻 11-04 侧栏方案，按 Awwwards 类前端展示重新设计）：顶部文字导航（回看、星空、资料库、收藏集、画布）加底部状态行，不用侧栏或浮动导航。资料库首屏以衬线大字搜索句为标题，细线控制栏承载范围、类型与观看方式；同一批资料提供 墙（图片原比例、文字为纸条、摘录为引文纸、链接为票据）、目录（编号行加悬停预览）、细看（单件居中、左题名右规格、下一件预告）三种尺度。详情为左物件、右细线规格表。墨夜底、稳定四色纸张（不代表类别）、月金强调；深浅两套主题共用 `src/sublime/workspace/archive/tokens.css` 的 `--mc-*`。呈现层集中在 `src/sublime/workspace/archive/`，旧 `--sw-*` 与 `--rw-*` 只作别名。依据与参考见 `../../docs/前端重设计-夜间档案馆-20261105.md`。浏览器验收页 `tests/redesign-fixture.html`（合成资料）。只改源码与预览，不替换已安装应用。
- 每次测试启动前验证候选配置的 userData、Vault 与桥接均位于隔离目录。构建后自动生成隔离配置，缺少配置时中止开发启动。
- 原 Vault 只读，保存、入库和关联笔记由用户明确提交。保留卡片标识、正文、附件、备注、收藏集、画布、草稿和回看状态。
- 本轮只构建独立桌面候选版，候选版使用独立名称、bundle ID、userData、Vault 与桥接目录。正式应用的目录不可作为自动验收目标。
- 自动验收使用合成资料与模拟 AI。真实 API、转录和网站抓取不纳入自动验收。产品已有手动 AI 入口沿用现有授权和交互。
- 保留原子事务、实体级冲突保护、多窗口通知、失败草稿恢复、退出等待保存和剪藏请求去重。
- 附件由主进程管理受控文件，浏览器存 Blob。迁移前备份并保留 v2，完整读回后才放行。回退必须覆盖迁移后新资料。
- JSX 使用 Prettier 160目标行宽。按职责拆分，每个本轮拆分文件不超过400行，单组件useState不超过8处。
- 统一检查运行仓库根 npm run check。所有构建与桌面操作验收记录写入根验收记录。
- 已被取代的决定与历史验收见 ../../docs/历史决定-前端.md，现行行为以本文件和用户本轮指令为准。
