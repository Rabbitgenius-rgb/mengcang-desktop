# 梦藏桌面工作台 · 阶段 0

这是梦藏的**可交互前端原型**，用于确认灵感、素材、藏书与阅读之间的页面组织、视觉方向和典型操作。当前阶段的通过结论只适用于本地原型范围，不代表正式桌面应用或真实知识库功能已经交付。

导航统一沿用图 1 的方向；各页按实际视口调整宽度与列数。素材在 1440px 宽度下为四列，在 1280px 下为三列。手机使用底部导航与可返回的详情界面，阅读工具栏分为两行。

## 可以体验什么

- **灵感**：搜索和筛选、新建与编辑、继续探索、确认或撤销整理、候选关联确认／跳过／撤回、从灵感建立本地项目入口。
- **素材**：类型、标签与项目筛选，选中详情、配文编辑、独立笔记预览、相关素材与原图查看。
- **藏书**：书名与作者搜索、阅读状态和分类筛选、书籍信息编辑、状态切换、继续阅读。
- **阅读**：示例翻页和页码跳转、正文缩放、当前页文字搜索、阅读笔记及草稿、示例引线确认和撤回、关系示例查看及移除／恢复。
- **设置与项目**：减少动态效果、本机草稿导出、项目入口建立与编辑。

阅读正文是可搜索的排版示例，页面和工具栏均标明“阅读示例”。演示书名、作者、出版信息、素材和候选依据不构成真实资料检索结果。候选关联与引线用于演示人工确认流程，并未调用真实 AI 服务。

## 保存位置与功能边界

编辑内容保存在当前浏览器、当前站点的 `localStorage` 中：

| 名称空间 | 保存内容 |
| --- | --- |
| `mengcang-desktop-preview-v1` | 灵感、素材、书籍、已保存阅读笔记、项目入口、当前页面和减少动态效果设置 |
| `mengcang-reader-preview-v1` | 按书籍与页码保存的阅读草稿、示例引线确认／撤回状态、关系示例移除／恢复状态 |

设置中的“导出预览草稿”会下载 JSON 副本，包含上述阅读状态。当前没有配套的导入恢复界面。清除浏览器站点数据会清除本机原型记录；不同浏览器或站点地址不会自动共享这些记录。保存失败时，界面会提示保留页面并复制或导出内容。

本阶段**尚未接入 Electron、Vault、真实 PDF 文件解析、备忘录同步、跨设备同步或真实知识库写入**。“在 Obsidian 打开”会展示未连接状态。阅读中的关系示例与确认操作只影响原型，不创建正式知识关系，也不修改 Personal AI OS 仓库。

## 预览与工程

当前本地预览地址为 [http://127.0.0.1:5209](http://127.0.0.1:5209)。开发服务使用 Vite；前端使用 React 与 Tabler 图标。页面正文和控件是原生前端界面，图片及书封来自提供的设计图裁切。

维护时可在项目根目录执行：

```sh
npm ci
npm run dev
```

构建使用 `npm run build`。工程保留了静态托管准备结构，产物为 `dist/client/index.html`、`dist/server/index.js` 与 `dist/.openai/hosting.json`；这不表示已经公开发布。`npm run test:sites` 检查静态资源、页面回退和打包文件，本轮文档记录时尚未运行该测试。

## 验证与交付说明

[设计验收记录](design-qa.md)记录了已完成的典型交互、截图、视口和证据边界。已检查 1440×900 的四个主要页面、1280×800 的素材页面，以及 390×844 的灵感、素材和阅读页面。

设计图中的图片与书封本身是小尺寸栅格图，放大后存在清晰度限制，记为 P3 已知限制。当前结论不覆盖完整 WCAG 合规、帧率验收、真实 PDF 性能、同步可靠性或桌面安装包验收。
