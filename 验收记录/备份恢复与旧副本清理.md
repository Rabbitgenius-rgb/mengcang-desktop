# 梦藏候选版备份恢复与旧副本清理验收

2026-11-04，在 Apple Silicon Mac 上启动已打包并通过本机签名验证的 0.9.0 候选版。三个独立桌面验收目录位于 `qa/acceptance-runs/`。所有原始笔记、回看记录和附件均为合成资料。

| 修复 | 观察到的结果 |
| --- | --- |
| 验收目录隔离 | 每个验收任务有自己的运行目录。恢复测试的来源工作区和目标工作区使用不同的资料库与桥接目录，指向同一份合成原始笔记。重启只读回本任务的资料。 |
| 原始卡片的整理信息恢复 | 在界面为原始卡片写备注、标星并归档，导出 ZIP，在空目标库确认「恢复备份」。关闭重开后，备注逐字一致，标星、隐藏状态和归档列表均正确。已有资料时选择「合并备份」，保留了目标库后来写的备注。 |
| 损坏附件修复 | 将目标图片等长篡改，确认恢复后，27,966 字节与备份原件逐字节相同；重开后图片可显示，原图宽 800 像素。另一个已有资料的工作区通过合并备份修复了仅由草稿引用的附件。 |
| 预览、取消和坏 ZIP | 预览完整备份、按 Esc 取消、载入第二个附件被篡改的 ZIP，三种操作均未在空目标库留下附件。自动化故障测试还覆盖实体事务失败及另一个写入同时使用相同附件。 |
| 旧副本清理 | 完成三次启动后，等长篡改一个草稿附件。点击清理收到校验失败提示，旧记录完整保留。用 ZIP 恢复后再次清理成功，独立迁移备份仍能读回，重启后新增笔记和草稿附件正常。 |
| 损坏的旧库 | 修改旧库样本的格式版本，再次启动后，新库以只读方式打开。从本机工具导出的 ZIP 中读到了迁移后新增的笔记、草稿和原附件字节。 |
| 附原件入库后的重试 | 暂时取消合成原始笔记目录的写权限，第一次保存失败。恢复权限，再次确认后沿用同一请求号，只生成一篇笔记和附件原件。 |
| 帮助文案 | 在桌面「关于本机资料库」与「粘贴备份内容」核对 ZIP、旧版兼容 JSON 和容量说明。单附件 64 MiB，ZIP 的文字清单 256 MiB，旧 JSON 的整个文件 256 MiB。 |
