| 跨库状态挂错卡 | 新 ZIP 记录来源身份与原文指纹。另一资料库里相同路径的旅行文章未收到旧备注、标星或隐藏状态。旧备注保留为独立恢复稿，本机图片卡和回看样本正常。 |

| 恢复中提前退出 | 恢复第二件附件暂停时调用真实 `app.quit()`。应用等待，释放后完成实体提交再退出，重启读回两张卡及两份图片。 |
| 改主题导致无法恢复 | 空目标库切到浅色后仍有「恢复备份」。恢复并重启后外观保持浅色，同库原始卡的备注、标星和隐藏状态正确。 |
| 合并零新增仍留附件 | ZIP 和 JSON 合并同 ID 的旧图片，目标保留已改成文字的卡片。实际新增为零，附件目录没有无引用新文件。 |
| 旧 JSON 修复与回滚 | JSON 与 ZIP 共用校验和暂存机制。损坏的第二张图能修复并重启显示。注入真实 IndexedDB 提交失败后，新写入的第一张图被清理，已有第二张图保留修复后的原件。 |
