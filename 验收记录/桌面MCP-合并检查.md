# 桌面 MCP 合并检查

检查日期：2026-10-06。对象：梦藏仓库的 `codex/desktop-mcp-checkpoint` 分支，包含 0.8.6 后续修复及 0.9.0 桌面只读 MCP。用户授权检查并合并源码；本轮没有替换或重开正式应用，没有创建新安装包 Release。

## 本次修复

工作区读取缺失、异常或超时后，旧实现仍会扫描文件库，并丢失工作区的隐藏名单；已隐藏资料因此可能被检索或读取。

现在先验证最新工作区的 schema、卡片及 savedIds/hiddenIds，包括稀疏数组。不能确认过滤时，所有内容及关联工具停止读取，不扫描文件库或原图；状态只报告不可读及未知数量。恢复后重新采用最新过滤。工作区有效而文件库单独失败时，仅返回安全的已保存工作区资料并明确标注部分可用。

新增 13 项回归，覆盖工作区缺失、错误、超时、结构异常、稀疏过滤、恢复使用最新隐藏名单，以及文件库失败时的安全部分读取。修复已完成独立只读复核。
