## 性能与附件读回

以下为本机合成资料库结果。标星与文字保存各采样 20 次，从同步更新调用开始，计时至持久化事务完成；P95 使用排序后第 `ceil(0.95 × n)` 个样本。不是点击到画面重绘的端到端时延，也不是跨机器性能承诺。

| 存储 | 合成附件规模 | 标星 P95 | 已有卡片文字保存 P95 |
| --- | --- | --- | --- |
| v2 基线 | 10 MiB | 109.8 ms | 111.5 ms |
| v2 基线 | 50 MiB | 502.6 ms | 600.7 ms |
| v2 基线 | 150 MiB | 1603.9 ms | 1799.2 ms |
| v3 | 500 MiB | 1.8 ms | 2.2 ms |

v3 的 500 MiB 由 10 份各 50 MiB 的不同合成 WAV 构成。重启后读回全部 524,288,000 字节并验证内容；三次新进程启动至资料库可操作分别为 **913、527、599 ms**。这些是关闭并重开的进程冷启动，未清除 macOS 文件缓存。

另在专用隔离库首次导入一份 50 MiB 附件：**480.9 ms**，包含附件解码、摘要、本机写入与实体事务，排除合成字节和 data URL 的准备时间；仅一次样本。关闭重开后对原文件做 SHA-256 和字节数核对，一致。

补测旧 0.9.0 实际界面：先持久化相应规模的 v2 合成资料、关闭再重开，等待样本卡可见，并成功打开详情。10、50、150 MiB 分别为 **577、1570、3083 ms**，每种一次，未清除操作系统缓存。读回附件总大小与辨别字节一致；该基线没有宣称逐附件全量摘要验证。

原 `governance-performance-*.json` 中的 `isolatedAppStartMs` 在对应规模的资料生成前结束，不能作为该规模的加载基线；以补测的独立冷启动记录为准。

原始数据：[v2 操作](governance-performance-baseline.json)、[旧版冷启动](governance-cold-baseline.json)、[v3 操作](governance-performance-v3.json)、[500 MiB 读回](governance-storage-acceptance.json)、[首次附件导入](governance-attachment-import.json)。

## 迁移、冲突与恢复

行为测试覆盖卡片 ID、正文、备注、收藏集、画布、草稿、回看状态的迁移读回，以及独立图片、文章图片、草稿附件和 AI 来源附件的外置。包含迁移备份失败、附件 IO 失败、旧版内容变化、并发实体修改、同卡冲突保留输入、三次不同启动计数与显式清理、中断清理后的恢复。

实际 Electron 小库演练顺序为：建立 v2 → 转换 v3 → 确认原 v2 未变 → 新增卡片并修改原卡备注 → 导出 ZIP 与兼容 JSON → ZIP 导入、v2 存储读回。核对迁移后的新增正文、修改备注、原附件及回看状态；这项小库演练与上述 500 MiB 原件读回是两项独立验证。

另已启动归档 0.9.0 的真实旧界面，使用“粘贴备份内容 → 预览 → 合并”导入兼容 JSON，再退出重开旧运行时。旧 UI 能搜到迁移后新增卡，整理面板显示修改后的备注；原正文、68 字节 PNG、标星、收藏集关系保持一致，回看 UI 分别核对未读、已读、归档各一条。该演练使用 5 张卡的小库，归档的旧应用资源由当前本机 Electron 执行；没有覆盖安装正式应用，也没有声称完成超过旧限额的降级。见[旧运行时回退结果](governance-legacy-runtime.json)。

超过旧版 256 MiB 兼容上限时，降级导出被明确阻止，保留 v3 完整备份路径。新 ZIP 的附件总量不受旧 JSON 的 256 MiB 限制，但 JSON 清单本身有 256 MiB 安全上限；不会输出本版无法导入的超大清单。

## 桌面与浏览器实际操作

已在打包后的独立 `.app` 中运行：关键词搜索与 Markdown → 图片详情与放大/Esc → 来源文章 → 本文摘录、配图定位 → 写关联笔记 → 资料库独立搜索及双向返回 → 整理备注与标星 → 回看 → 关闭重开，读回笔记、备注、标星及回看归档。使用合成的万维网文章和概念图，没有重新添加正式库中已删除的测试内容，也未调用真实模型。

浏览器预览走完新建、保存、刷新读回、收藏集创建与归属、ZIP 下载并解析。检查 1440×900、390×844 两种尺寸，所测页面无横向溢出；菜单首项聚焦、方向键、Esc 返焦通过。可见文字抽查 25 个节点，最低 6.15:1，0 个低于 4.5:1；仅代表所测页面状态，不是整应用无障碍认证。
